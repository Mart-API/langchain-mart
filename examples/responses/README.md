# Complete response examples

These are complete illustrative responses using fictional public-demo identities, not live recordings or field-coverage guarantees. Missing fields may be null or empty in real results. The tools preserve the full API response without projecting fields.

`profile.json` shows profile-only mode. `profile-with-email.json` shows the response shape when `MartToolkit(include_email=True)` is used. Its fictional email and confidence value illustrate the contract; they are not a successful live lookup. The meeting example's `--demo` uses profile-only mode.

Company, Refresh and Posts examples are in the matching JSON files. Employee expansion, comments and member expansion are not enabled by these examples.
